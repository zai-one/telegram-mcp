# Telegram MCP

MCP-сервер для чтения переписки и отправки сообщений в Telegram из AI-ассистента. Подключается к пользовательскому аккаунту Telegram, позволяет искать сообщения, получать контекст диалога, находить получателей и проверять статус отправки.

## Что умеет

- Просмотр чатов и входящих сообщений, поиск по переписке и получение контекста диалога.
- Поиск и уточнение получателя перед отправкой сообщения или ответа.
- Пакетная отправка сообщений и просмотр статуса исходящих при включённой записи.

## Установка

Нужны Git, [uv](https://docs.astral.sh/uv/getting-started/installation/) и Python 3.12–3.14.

Нужны Telegram API ID, API hash и сессия пользовательского аккаунта. Локальный настройщик может создать сессию через интерактивный вход. Токен бота не заменяет пользовательскую сессию. См. [настройку входа в Telegram](INSTALL.md#from-a-clone-or-source-zip).

```sh
git clone https://github.com/zai-one/telegram-mcp.git
cd telegram-mcp
uv sync --frozen
uv run --frozen python scripts/configure.py
uv run --frozen zai-telegram-mcp --config mcp.local.json --check-config
uv run --frozen zai-telegram-mcp --config mcp.local.json
```

Настройщик сохраняет данные только локально. `--check-config` проверяет локальную
конфигурацию без запросов к провайдеру. Последняя команда ждёт подключения MCP-клиента.

Инструкции подключения и установки пакета: [INSTALL.md](INSTALL.md).

## Возможности и ограничения

По умолчанию доступно только чтение. Для отправки нужны отдельные права; неполный поиск получателя не считается подтверждённым совпадением. Передача медиа и поток событий в этот интерфейс не входят. Подробнее: [доступ и отправка сообщений](docs/RUNTIME.md).
